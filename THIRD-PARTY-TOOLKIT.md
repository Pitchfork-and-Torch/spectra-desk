### How Spectra Desk uses it

Spectra Desk v7 includes a **native reimplementation** of Exploratores-class capabilities:

1. A **factual catalog of public search URL templates** (`server/src/data/toolkit-catalog.json`), generated by `scripts/import-exploratores-catalog.mjs` from a local Exploratores checkout.
2. TypeScript modules for catalog load, indicator classification, operator URL packs, PII redaction, and IBAN validation — **written for Spectra Desk**, not copied from Exploratores JS.

Spectra Desk remains **proprietary** (`UNLICENSED`). We do **not** distribute Exploratores application source, HTML pages, CSS, CyberChef bundle, or bank database JS as part of Spectra Desk.

### What is not included

- Exploratores `pages/`, `assets/css/`, `assets/js/main.js`, validators, CyberChef under `tools/cc/`
- AGPL-covered program code as a linked module

### Regenerating the catalog

```bash
git clone https://github.com/SOsintOps/Exploratores.git
node scripts/import-exploratores-catalog.mjs path/to/Exploratores
```
